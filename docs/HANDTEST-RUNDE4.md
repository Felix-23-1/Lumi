# Handtest Runde 4 (Lumi) – nur das Neue, wichtigstes zuerst

Hakt etwas: Einstellungen → Allgemein → **„Diagnose exportieren“** und die Datei mitschicken.

## 1. Muss gehen (10 Minuten)
- [ ] Lumi startet als **Lumi** (Name im Menü, Notch), deine Aufgaben/Notizen/Einstellungen sind noch da.
- [ ] Chat: Antwort erscheint **Wort für Wort**; „Abbrechen“ stoppt sofort.
- [ ] Erster Chat mit Cloud-Modell → **Einwilligungs-Karte** erscheint einmal; „Einverstanden“ → danach normal.
- [ ] Einstellungen → Datenschutz → **„Nur lokal“** an → Chat antwortet über **Apple Intelligence**; „Merk dir: …“ fragt nach und speichert.
- [ ] Notch geschlossen: Lumi bleibt ruhig, der Mac fühlt sich nicht langsamer an (Aktivitätsanzeige → Lumi: CPU im Leerlauf nahe 0 %).
- [ ] Erinnerung zu einer Aufgabe → Hinweis mit **„Erledigt“** und **„In 10 Min“**; beides wirkt.
- [ ] Heute → **„Was jetzt?“** → zeigt eine Aufgabe mit Grund und startet den Fokus.
- [ ] Tagesplan → ⓘ an einem Block zeigt, **warum** er dort liegt.

## 2. Sollte gehen
- [ ] Einstellungen → Modell: anderer **Anbieter** (z. B. OpenAI) mit eigenem Schlüssel → „Verbindung testen“ ok; zurück zu OpenRouter → alter Schlüssel noch da.
- [ ] **Lokal (Ollama/LM Studio)**, falls installiert: „Modelle laden“ zeigt Modelle, Chat antwortet.
- [ ] Löschen → **Rückgängig** mehrfach (Banner „+N“).
- [ ] Heute → Suche findet **Mail- und Chat-Treffer** und öffnet den richtigen Reiter.
- [ ] Chat: **„/“** zeigt Skills; „/abschluss“ öffnet einen **Mail-Entwurf** (sendet nicht).
- [ ] Mods → Bibliothek: **Feiertage** und **Pomodoro** einschalten → Notch-Text erscheint.
- [ ] Einstellungen → Allgemein → **Diagnose exportieren** → Datei auf dem Schreibtisch, darin keine Schlüssel/Mail-Texte.

## 3. Nur wenn du es nutzt
- [ ] **CalDAV** (Nextcloud/iCloud mit App-Passwort): Kalender erscheint, Termin anlegen landet dort.
- [ ] **IMAP direkt**: Mails erscheinen; WLAN aus → Lumi hängt nicht, zeigt „nicht erreichbar“.
- [ ] **MCP-Server** eintragen → „Testen“ listet Werkzeuge; schreibende fragen nach.
- [ ] **Obsidian-Ordner** wählen → Suche findet Notizen daraus.
- [ ] **Datenschutz → Protokoll** zeigt deine letzten Aktionen.

## 4. Freunde-Update
- [ ] Ein Freund mit alter **Taby**-Version: Einstellungen → Updates → „Jetzt aktualisieren“ → danach heißt die App Lumi, Daten sind da.
